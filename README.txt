RELOJ — PWA minimalista

Gestos
- Toca una vez para activar pantalla completa, mantener la pantalla despierta y habilitar sonido.
- Desliza a la izquierda para abrir la personalización.
- Desliza a la derecha o toca fuera del panel para cerrarla.

El panel usa iconos:
- Escudo: protección OLED (mueve el reloj 1–2 píxeles cada cinco minutos).
- Calendario: mostrar/ocultar fecha; al ocultarla queda el modo solo hora.
- 24: formato de 24 horas.
- Paleta: color automático según la hora.
- Batería: muestra un icono de carga cuando el navegador ofrece ese dato.
- Luna + dos horas: brillo visual nocturno y su horario.
- Altavoz + deslizador: silenciar y volumen del click.
- Campana + hora: activar y configurar alarma.

Notas
- Los ajustes se guardan automáticamente en el dispositivo.
- La alarma funciona mientras Reloj está abierto/visible. El navegador no permite garantizar alarmas si la PWA está cerrada por completo.
- Mantener la pantalla activa usa Screen Wake Lock tras el primer toque. Si el navegador o dispositivo no es compatible, el sistema aplicará sus propias reglas de ahorro de energía.
